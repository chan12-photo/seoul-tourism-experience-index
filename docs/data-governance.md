# 데이터 공개 정책

## 기본 원칙

이 저장소는 **코드 공개와 데이터 공개를 분리**합니다. 분석에 사용했다는 사실이 재배포 권한을 의미하지 않습니다. 출처와 이용약관, 반출 승인 범위를 확인하기 전에는 원천자료뿐 아니라 가공·집계 자료도 Git에 추가하지 않습니다.

## 공개하지 않는 자료

- 서울 빅데이터캠퍼스에서 열람하거나 반출한 원천·중간 데이터
- 캠퍼스 자료를 단순 집계하거나 정규화한 값
- API 응답 원문과 서비스 제공자가 재배포를 허용하지 않은 지오코딩 결과
- 주소, 전화번호, 사업자 정보 등 분석 목적에 불필요한 식별 가능 필드
- Shapefile, Excel, Numbers와 대용량 CSV 원본
- API 키, 토큰, `.env`, 인증 헤더와 키가 남은 실행 로그
- 팀원 동의를 받지 않은 보고서·발표자료 원본

빅데이터캠퍼스 반출 정책은 원자료뿐 아니라 단순 집계값과 결과 예시가 포함된 코드도 제한할 수 있습니다. 공개 전에는 해당 데이터의 반출 승인서와 최신 정책을 다시 확인해야 합니다.

## 공개 가능한 후보

- 원자료 없이 실행 가능한 전처리 함수와 테스트
- 컬럼 스키마, 데이터 사전, 방법론과 검증 규칙
- 공급기관이 명시적으로 재배포를 허용한 공개 데이터
- 재배포 권한이 확인된 자료에서 만든 비식별 결과
- 실제 분포를 복원할 수 없는 합성 테스트 데이터

## 비밀정보 대응

원본 작업 폴더에서 Kakao와 TMAP 키 파일이 발견됐습니다. 공개 저장소에서 파일을 삭제하는 것만으로는 안전하지 않습니다.

1. 기존 키를 제공자 콘솔에서 폐기합니다.
2. 새 키를 발급하고 도메인·IP·API 권한을 최소화합니다.
3. 키는 로컬 환경변수나 비밀관리 도구로만 주입합니다.
4. Git 커밋 전 `tei-pipeline check-public .`을 실행합니다.
5. 실수로 커밋했다면 키를 먼저 폐기하고 Git 기록에서도 제거합니다.

## 출처 기록

공개가 승인된 데이터마다 다음 정보를 `data/README.md`에 추가해야 합니다.

- 데이터셋 정식 명칭과 제공기관
- 원문 URL과 조회·다운로드 날짜
- 적용 기간과 행정구역 기준연도
- 라이선스 또는 반출 승인 범위
- 원본 파일 해시
- 원본에서 최종 변수까지의 변환 단계
