# 데이터 공개 정책

## 원칙

이 저장소는 코드와 데이터를 따로 공개합니다. 분석에 사용했다고 해서 재배포 권한이 생기는 것은 아니므로, 데이터셋별 이용 조건을 확인하기 전에는 원천자료와 행정동별 가공자료를 Git에 추가하지 않습니다.

- **최종 분석의 원천 데이터**: 모두 공공데이터입니다([data/README.md](../data/README.md)).
- **빅데이터캠퍼스 자료**: 중간보고서 단계의 수요지수(Y1)에는 서울 빅데이터캠퍼스 카드매출 자료를 썼습니다. 최종에서는 한국관광공사 데이터랩 자료로 바꿨기 때문에 최종 결과에는 쓰이지 않았습니다.
- **팀 공동 결과물**: 그림 등 팀 공동 결과물의 공개는 팀원 동의를 받았습니다.

## 저장소에 넣지 않는 자료

- 원천 데이터와 행정동별 가공 CSV
- Kakao API 응답과 지오코딩 결과 원문
- 주소·전화번호 등 분석에 필요 없는 식별 가능 필드
- Shapefile, Excel, 압축파일과 대용량 원본
- API 키, 토큰, `.env`, 인증 헤더가 남은 실행 로그
- 팀 보고서·발표자료 원본

## 공개하는 자료

- 원자료 없이 실행되는 전처리 함수와 합성 데이터 테스트
- 컬럼 스키마, 데이터 사전, 방법론과 검증 규칙
- 집계 결과 그림(`assets/`). 산점도의 점은 행정동별 최종 지수의 위치를 보여 주지만, 행정동별 수치 표는 포함하지 않습니다.

## 비밀정보

API 키는 환경변수로만 주입하며, 커밋 전에 `tei-pipeline check-public .`을 실행합니다. 키가 커밋되었다면 기록을 지우기 전에 먼저 키를 폐기합니다. 자세한 내용은 [SECURITY.md](../SECURITY.md)를 보세요.
