# 연구 한계

## 시간과 행정구역

변수별 기준시점이 서로 다르고 행정동 개편 시점도 완전히 일치하지 않습니다. 424개 또는 427개 행을 426개 기준으로 바꾼 과정은 변환표와 근거를 별도로 공개해야 합니다.

## 거리 대리변수

D2는 행정동 중심점과 4개 관광거점 사이의 직선거리입니다. 실제 보행·대중교통 이동시간, 환승, 배차간격과 관광객의 출발지 분포를 반영하지 못합니다.

## 지오코딩과 분류

관광지와 문화유산 지오코딩 실패가 많고, 명칭·키워드 기반 분류에는 오분류 가능성이 있습니다. 특히 C3 분류 완료율이 약 69%이므로 사전과 수작업 검토 절차에 따른 민감도 분석이 필요합니다.

## PCA 해석

PCA 제1주성분은 각 축의 모든 정보를 보존하지 않습니다. D축의 KMO와 내적 일관성이 낮아 하나의 잠재요인으로 단정하기 어렵습니다. 축 점수를 표준화하지 않고 결합하면 설명분산이 큰 축의 영향력이 커질 수 있습니다.

## 공간통계

인접 행정동 간 공간적 자기상관을 검증하지 않았습니다. Pearson 상관계수의 유의확률은 공간적 독립성이 충족된다는 가정 아래 계산되므로 과도하게 해석해서는 안 됩니다.

## 외부 타당성

정답 레이블이나 별도 관광만족도 자료를 이용한 외부 검증이 없습니다. 사분면은 정책 후보 선별 도구이지 정책 효과의 인과적 증거가 아닙니다.

## 개선 방향

- 실제 대중교통 이동시간과 환승 데이터를 이용한 접근성 측정
- 행정동 경계 변경 이력을 반영한 시계열 정합화
- Moran's I, 공간회귀 등 공간의존성 분석
- 분류 사전 공개와 표본 이중검토를 통한 정확도 측정
- 축별 가중치와 결측 처리 방식에 대한 민감도 분석
- 별도 연도 또는 외부 관광지표를 이용한 검증
