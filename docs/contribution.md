# 기여 범위

## 프로젝트 성격

본 연구는 3인 팀 프로젝트이며 최종보고서에 기록된 업무 분담을 기준으로 개인 기여를 구분합니다.

## 박찬일 담당

- 문화자원 C축과 교통 접근성 D축 지표 후보 설계
- C/D축 원천자료 수집과 서울 빅데이터캠퍼스 현장 데이터 확보
- 문화시설·관광지·문화유산·지하철역·버스정류장의 행정동 단위 가공
- 관광지와 문화유산 지오코딩, 분류, 품질검사
- C/D축 분석 방법론 문서화
- 공급-수요 2·4사분면 결과 해석
- 정책 제안과 연구 한계 작성

## 팀 공동 또는 다른 담당

- 전체 연구질문과 TEI 프레임 구성
- 음식 A축과 상권 B축 데이터 수집·지표화
- 관광소비 Y1과 단기체류 외국인 생활인구 Y2 구축
- 전체 PCA 진단, 최종 사분면 지도와 발표자료 통합

## 포트폴리오 표현 원칙

권장 표현:

> 3인 팀 프로젝트에서 문화자원(C)·교통 접근성(D) 축을 담당해 이질적인 공간자료를 426개 행정동 단위로 통합하고, 지오코딩·공간결합·품질검증 파이프라인을 구현했다. 분석 결과를 바탕으로 공급 대비 관광수요가 높은 지역의 정책 대안을 제안했다.

피해야 할 표현:

- TEI 전체를 단독으로 설계·구현했다는 주장
- 팀원이 담당한 A/B/Y축을 본인 성과로 서술
- 4사분면 후보를 검증 완료된 정책 대상지로 표현
- 직선거리 변수를 실제 대중교통 이동시간으로 표현
