# 분석 방법론

## 1. 분석 단위

분석 단위는 서울시 426개 행정동입니다. 서로 다른 시점과 행정구역 체계를 사용하는 원천자료를 동일한 행정동 코드와 `자치구_행정동` 키에 맞춰 결합했습니다. 경계에 위치한 점 자료는 좌표계와 공간결합 결과를 별도로 확인해야 합니다.

## 2. 공급지수 X

관광 경험을 음식(A), 상권(B), 문화(C), 교통 접근성(D)으로 나누고 각 축의 표준화된 변수에 PCA를 적용했습니다. 축별 제1주성분을 대표 점수로 사용한 뒤 동일 가중치로 결합했습니다.

원 연구는 축별 PC1을 추가 표준화하지 않고 평균했습니다. PC1 분산이 축마다 달라 명목상 동일 가중치와 실제 영향력이 달라질 수 있습니다. 이 저장소의 기본 모드는 각 PC1을 다시 z-score로 표준화한 후 평균하며, `score_scale="none"`으로 원 연구 방식을 재현할 수 있습니다.

## 3. C축 문화자원

### C1 문화공간

문화시설 좌표를 행정동 경계와 공간결합해 시설 수를 집계했습니다. 보고서에는 분석대상 1,052개로 기재됐지만 최종 행정동 집계 합계는 1,051개입니다. 공개 결과에는 좌표 누락 또는 경계 미매칭 1건을 명시해야 합니다.

### C2 관광지

5개 언어 자료 2,358건의 고유 관광지 ID를 기준으로 주소·명칭 후보를 만들고 Kakao Local API로 지오코딩했습니다. 최종 유효 좌표는 1,009건이었습니다. C2는 다른 문화 변수와의 중복성 검토 후 최종 C축 PCA에서 제외했습니다.

### C3 콘텐츠 구성

유효 관광지를 다음 네 범주로 분류했습니다.

- 전통·역사
- 문화·예술
- 자연·힐링
- 현대·한류·라이프스타일

최종 분류 건수는 696건으로 전체 유효 관광지의 약 69.0%입니다. 미분류 140건과 지원시설 제외 173건이 있으므로 분류 사전과 검토 규칙을 결과 해석에 함께 제시해야 합니다.

### C4 분류 완료율

행정동별 `네 범주 분류 건수 / 전체 관광지 수`로 계산했습니다. 관광지 수가 0인 행정동은 0으로 처리했습니다. 이 변수는 관광 콘텐츠 정보가 얼마나 구체적으로 구축됐는지를 나타내며, 실제 관광자원의 품질을 직접 측정하지는 않습니다.

### C5 장소형 문화유산

문화유산 원자료 2,079건에서 무형유산 87건을 제외해 1,992건을 지오코딩 대상으로 삼았습니다. 이 중 좌표 확보 380건, 유효 판정 315건, 장소형 키워드 후보 273건을 거쳐 행정동에 최종 집계된 건수는 271건입니다. `log1p(count)`를 사용해 종로권의 극단적인 집중을 완화했습니다.

`2,079건`과 `1,992건`은 모순된 원자료 수가 아니라 각각 전체 수집 건수와 무형유산 제외 후 지오코딩 대상 건수입니다.

## 4. D축 교통 접근성

### D1 지하철역 수

역 좌표를 행정동 경계에 결합하고 중복 역 식별자를 제거한 뒤 행정동별로 집계했습니다.

### D2 주요 관광거점 거리

행정동 중심점에서 명동역, 홍대입구역, 강남역, 서울역까지의 Haversine 직선거리를 계산하고 최솟값을 선택했습니다. 거리가 짧을수록 접근성이 높도록 PCA 입력에는 거리의 음수값 `D2_access`를 사용했습니다.

초기 파일명에 TMAP이 포함됐지만 최종 계산은 TMAP 이동시간이 아닙니다. 과도한 API 호출과 불완전한 수집으로 인해 직선거리 대리변수를 사용했습니다.

### D3 버스정류장 수

정류장 좌표를 행정동에 공간결합하고 고유 정류장 식별자로 중복을 제거한 뒤 집계했습니다. 초기 코드의 `D4`를 최종보고서의 `D3`으로 재명명했습니다.

## 5. PCA와 지수 결합

1. 각 입력 변수를 평균 0, 표준편차 1로 표준화합니다.
2. 특이값 분해로 축별 제1주성분을 계산합니다.
3. 모든 입력이 많을수록 긍정적인 방향이 되도록 주성분 부호를 정렬합니다.
4. 권장 모드에서는 축별 PC1을 다시 표준화합니다.
5. A·B·C·D 축을 산술평균해 공급지수 X를 계산합니다.

원 연구의 진단 결과는 C축 KMO 0.762, Cronbach's alpha 0.790, PC1 설명력 51.454%였습니다. D축은 KMO 0.475, alpha 약 0.04로 낮아 단일 잠재요인으로 해석하는 데 주의가 필요합니다.

## 6. 수요지수 Y와 사분면

Y1은 한국관광 데이터랩 관광소비 자료의 2025년 6월부터 2026년 5월까지 기간을, Y2는 2025년 1월부터 6월까지의 단기체류 외국인 생활인구를 사용했습니다. Y2에는 로그 변환을 적용하고 두 지표를 1~20 범위로 변환한 뒤 평균했습니다.

공급과 수요의 중앙값을 기준으로 사분면을 구성했습니다. 4사분면은 수요가 높고 공급이 낮은 후보 지역이며, 현장 확인과 공간적 자기상관 검증 없이 정책 우선순위로 확정해서는 안 됩니다.
