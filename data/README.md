# Data directory

실제 연구 데이터는 이 저장소에 포함하지 않습니다. `raw`, `interim`, `processed` 폴더는 로컬 실행 위치만 정의하며 `.gitignore`로 보호됩니다.

| 폴더 | 용도 |
|---|---|
| `raw/` | 공급기관에서 받은 변경하지 않은 원본 |
| `interim/` | 좌표 정제, 지오코딩, 공간결합 등 중간 결과 |
| `processed/` | PCA와 최종 분석에 사용하는 행정동 단위 변수 |

새 데이터를 추가하기 전 `docs/data-governance.md`에서 재배포 가능 여부를 확인하고, 데이터명·기관·URL·기준일·라이선스·SHA-256 해시를 이 문서에 기록해야 합니다.
