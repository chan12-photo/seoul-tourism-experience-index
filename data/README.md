# Data directory

실제 분석 데이터는 이 저장소에 포함하지 않습니다. `raw`, `interim`, `processed` 폴더는 로컬 실행 위치만 정의하며 `.gitignore`로 보호됩니다.

| 폴더 | 용도 |
|---|---|
| `raw/` | 공급기관에서 받은 변경하지 않은 원본 |
| `interim/` | 좌표 정제, 지오코딩, 공간결합 등 중간 결과 |
| `processed/` | PCA와 최종 분석에 사용하는 행정동 단위 변수 |

## 최종 분석에 사용한 데이터 (팀 최종보고서 기준)

| 축 | 데이터 | 제공처 |
|---|---|---|
| 공통 | 서울시 행정구역(동별) 통계, 행정동 경계 | 서울 열린데이터광장, 브이월드 |
| A 음식 | 서울시 식품위생업소 현황, 전국전통시장 표준데이터 | 서울 열린데이터광장, 공공데이터포털 |
| B 상권 | 서울시 상권분석서비스(점포·추정매출·집객시설·영역) | 서울 열린데이터광장 |
| C 문화 | 문화공간 전체 목록 | 서울문화포털 |
| C 문화 | 서울특별시 관광명소 | 공공데이터포털 |
| C 문화 | 서울시 소재 문화재 지정 현황 | 서울 열린데이터광장 |
| D 교통 | 서울시 역사마스터 정보, 버스정류소 위치정보 | 서울 열린데이터광장 |
| D 교통 | 주요 관광·상업 거점 좌표 | 팀 내부 작성 |
| Y 수요 | 지역별 외국인 관광지출액 | 한국관광공사 데이터랩 |
| Y 수요 | 행정동 단위 서울 생활인구(단기체류 외국인) | 서울 열린데이터광장 |

관광지와 문화유산 좌표는 Kakao Local API로 지오코딩했습니다. 데이터를 저장소에 추가하려면 먼저 `docs/data-governance.md`에서 재배포 가능 여부를 확인하고, 데이터명·기관·URL·기준일·라이선스·SHA-256 해시를 이 문서에 기록해야 합니다.
